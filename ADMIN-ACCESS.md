The studio manages profile and portrait, clinic address, location link, WhatsApp booking number and message, detailed expertise pages, education and experience, articles, videos, FAQs, social links, and public page wording. Save changes to update the live site.

To authorize the doctor, configure server-only `ADMIN_EMAILS` with her verified ChatGPT sign-in email. Multiple emails are comma-separated. Content editing and image uploads use the same server-side authorization check; visitors cannot grant themselves access through content fields. Keep this value out of public content and client-side environment variables.
